# 채씨 메타데이터 리더 1.1.1

Windows x64 · 빌드 `reader-20261128-01-public` · 순번 `2026112801`

[최신 안정판](https://github.com/DooMokDdongGae/Chaessi-Metadata-Reader/releases/tag/v1.1.1)

새 설치와 지원되는 공식 구판 업데이트에 같은 **Chaessi-Metadata-Reader-Setup-x64.exe**를 사용합니다. 새 설치의 기본 위치는 `%LOCALAPPDATA%\Programs\ChaessiMetadataReader`이며 안전한 로컬 폴더를 선택할 수 있습니다. 공백·한글 경로를 지원하며, 업데이트는 검증된 기존 설치 위치를 유지합니다. 기존 Chrome 확장 **0.3.1**은 변경하지 않았습니다.

[English](README.en.md) · [日本語](README.ja.md) · [릴리스 노트](RELEASE-NOTES.ko.md)

NovelAI Inspect에서 이미지의 프롬프트를 가져와 편집하고, 원하는 문구를 CHAESSI PRESET의 베이스·캐릭터 칸에 보내는 Windows 프로그램입니다. NovelAI와 독립적으로 개발했습니다.

## Codex·Claude Code·GPT에 설치 도움 요청하기

아래 지시문 전체를 사용하는 AI에 붙여넣으세요. AI가 PC를 조작할 수 있는지는 도구와 정책에 따라 다릅니다. 연결키는 이 지시문에 포함하지 마세요.

    채씨 메타데이터 리더 1.1.1과 Chrome 확장 0.3.1을 내 Windows x64 PC에 설치하고 연결하도록 도와줘.
    먼저 네가 사용할 수 있는 PC·브라우저 도구를 확인해. 지원되는 단계만 직접 돕고, 조작할 수 없는 단계는 내가 누를 버튼을 하나씩 알려줘. 사용자 승인, UAC, 보안·권한 확인은 네 도구 정책에 따라 내가 직접 처리하게 해. 차단이나 조직 정책을 우회하지 마.

    1. 아래 공식 1.1.1 릴리스에서 Chaessi-Metadata-Reader-Setup-x64.exe, 필요하면 Chaessi-Metadata-Reader-Chrome-Extension.zip, SHA256SUMS.txt를 받아 파일명과 SHA-256을 대조해. 페이지가 아직 없거나 파일·해시가 맞지 않으면 멈추고 알려줘.
    https://github.com/DooMokDdongGae/Chaessi-Metadata-Reader/releases/tag/v1.1.1
    같은 Setup이 새 설치와 지원되는 공식 구판 업데이트용이야. 새 설치는 %LOCALAPPDATA%\Programs\ChaessiMetadataReader를 기본으로 하며 안전한 로컬 폴더를 선택할 수 있어. 공백·한글과 다른 드라이브도 지원해. 업데이트에서는 검증된 기존 설치 위치를 유지하고 직접 파일을 옮기지 마. 리더를 정상 종료하고 안내를 읽어 설치해. 코드 서명이 없는 설치기이므로 해시가 다르거나 정책이 막으면 중단해. 기존 키·언어·프리셋 지정·Chrome 프로필과 사용자 자료를 보존해.

    2. Chrome 확장 0.3.1이 이미 정상 연결돼 있으면 원래 폴더·프로필·페어링을 유지하고 재설치·재페어링·중복 설치하지 마. 처음 설치할 때만 ZIP을 계속 사용할 고정 폴더에 풀어. 내가 사용할 Chrome 프로필에서 chrome://extensions를 열고 개발자 모드 → 압축해제된 확장 프로그램을 로드 → manifest.json이 든 폴더를 내가 선택하도록 안내해. ‘채씨 메타데이터 리더 연결’ 0.3.1 카드가 하나인지 확인하고 폴더를 이후 이동·삭제하지 않게 알려줘.

    3. 처음 연결할 때만 리더의 Chrome 연결 설정 → 연결키 복사를 안내해. 그 키는 내가 이 PC 확장 설정의 ‘리더의 연결 키’ 칸에만 붙여넣고 ‘최초 연결 저장’을 누를게. 키나 키 파일을 요청하지 말고 채팅·로그·스크린샷·외부 서비스로 보내지 마. ‘NovelAI Inspect 접근 허용’ 뒤 Chrome의 최초 권한 요청은 내가 확인하게 해. 리더의 Chrome 연결됨 표시를 확인하고 설정 탭을 닫은 뒤, 같은 Chrome 프로필과 리더를 다시 열어 재연결을 확인해. 기존 연결을 임의로 재설정하지 마.

    4. NovelAI Inspect의 Simplified에서 이미지를 확인하고 리더에서 가져와 편집하는 법을 알려줘. Preset 3.9.1은 아래 별도 공식 릴리스에서 ZIP을 받아 SHA-256을 확인하고 고정 폴더에 풀어. 공개 준비가 병행될 수 있으므로 페이지나 ZIP이 아직 없으면 있다고 가정하지 마.
    https://github.com/DooMokDdongGae/Chaessi-Preset/releases/tag/v3.9.1
    Chaessi-Preset-v3.9.1-x64.exe와 서명·명세 파일 4개를 함께 보관해. 리더의 실행 파일 선택/변경에서 그 고정 EXE를 한 번 지정하고, 임시로 풀린 내부 EXE는 선택하지 마. 먼저 실행돼 있어도 같은 파일 경로로 연결해. 기존 공식 3.8.5는 2026-11-23 수정본만 별도 지원해. 모든 미래 버전의 호환을 가정하지 마. 받을 Base/Character Positive/Undesired 칸과 추가/덮어 쓰기를 정하고 프리셋으로 보내기 → 프리셋의 변경 확인 → 적용 또는 취소 순서로 안내해. 적용 후에는 Undo로 되돌릴 수 있어. 서명 검증 예외를 만들지 마. 설치 확인에 내 이미지·프롬프트의 외부 전송이나 이미지 생성 API 호출은 필요 없어.

## Windows와 Chrome에 설치하기

Windows 10 또는 11 x64와 Chrome 120 이상을 준비하세요. 리더에는 Python과 Tk가 포함되어 있습니다. 별도 개발 도구를 설치할 필요가 없습니다.

1. [공식 1.1.1 릴리스](https://github.com/DooMokDdongGae/Chaessi-Metadata-Reader/releases/tag/v1.1.1)에서 **Chaessi-Metadata-Reader-Setup-x64.exe**와 필요하면 **Chaessi-Metadata-Reader-Chrome-Extension.zip**을 받으세요. Windows PowerShell에서 `Get-FileHash -Algorithm SHA256 "파일 이름"`으로 각각 계산해 릴리스의 SHA-256과 대조할 수 있습니다.
2. Reader가 열려 있으면 작업을 마치고 정상 종료하세요. 같은 **Setup**으로 새로 설치하거나 기존 공식판을 업데이트할 수 있습니다. 시작 메뉴에서 **Chaessi Metadata Reader**를 여세요. 신규 설치 시 바탕 화면 바로가기를 선택할 수 있습니다.
3. 확장 0.3.1이 이미 연결돼 있으면 기존 확장을 그대로 쓰세요. 처음 설치할 때는 확장 ZIP을 계속 보관할 폴더에 압축을 푸세요. 사용할 Chrome 프로필에서 주소창에 `chrome://extensions`를 입력하고 **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**에서 **manifest.json이 들어 있는 폴더**를 선택하세요.
4. 확장 카드에 **채씨 메타데이터 리더 연결**과 **0.3.1**이 표시되는지 확인하세요. Chrome은 이 폴더에서 확장을 읽으므로 설치한 위치에 그대로 두세요. [Chrome의 폴더 선택 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

## 처음 한 번 연결하기

1. 리더에서 **Chrome 연결 설정 → 연결키 복사**를 누르세요. Chrome의 확장 메뉴에서 리더 확장을 눌러 설정 탭을 엽니다.
2. **리더의 연결 키**에 붙여넣고 **최초 연결 저장**을 누르세요. 같은 탭에서 **NovelAI Inspect 접근 허용**을 누르고 Chrome의 `novelai.net` 권한 요청을 확인한 뒤 허용하세요.
3. 리더에서 **Chrome 연결됨**을 확인하면 설정 탭을 닫으세요. 다음부터 같은 프로필의 Chrome과 리더를 열면 자동으로 다시 연결됩니다. Chrome의 절전 상태에 따라 30초 이상 걸릴 수 있습니다.

## 이미지에서 프리셋 초안까지

1. Chrome에서 NovelAI Inspect에 이미지를 열고 **Simplified** 내용을 확인하세요. 리더에서 **NovelAI Inspect 가져오기**를 누르세요. 가져올 탭이 여러 개면 원하는 Inspect 탭을 먼저 선택하세요.
2. **가져온 이미지**에서 이미지를 골라 베이스·캐릭터의 **긍정 프롬프트** 또는 **제외 프롬프트**를 편집하세요. **문구 복사**는 현재 편집값을 복사합니다. **수집 원문 보기**로 원문을 확인하고 **원문으로 복원**으로 한 칸을 되돌릴 수 있습니다.
3. 필요한 글을 드래그해 **선택 문구 담기**를 누르거나, 한 칸 전체를 보내려면 **전체 문구 담기**를 누르세요. 담긴 항목은 그때 만든 사본입니다. 편집 후 달라진 문구가 필요하면 다시 담으세요.
4. **프리셋으로 보내기 → 실행 파일 선택/변경**에서 별도 공식 ZIP에서 EXE와 서명·명세 파일 4개를 함께 푼 `Chaessi-Preset-v3.9.1-x64.exe` Portable을 한 번 선택하고 확인하세요. **프리셋 연결**을 누르면 지정한 파일에 해당하는 실행 중인 프리셋을 확인하거나, 꺼져 있으면 리더가 실행합니다. [CHAESSI PRESET v3.9.1 안내](https://github.com/DooMokDdongGae/Chaessi-Preset/releases/tag/v3.9.1)
5. 보낼 행을 고르고 **받을 프롬프트 칸**을 지정하세요. **추가**는 두 문구 사이에 쉼표와 공백 한 칸을 넣어 이어 붙이고, **덮어 쓰기**는 해당 칸을 교체합니다. 한쪽이 비어 있으면 구분자를 넣지 않습니다. 모든 행의 받을 칸을 지정한 뒤 **프리셋으로 보내기**를 누르세요. 목록 전체를 위에서부터 한 번에 보냅니다. 한 문구만 보내려면 다른 항목은 목록에서 빼세요. 원문과 편집창의 내용은 유지됩니다.
6. **프리셋 창**에서 변경 전후를 읽고 적용하거나 취소하세요. 적용한 직후에는 프리셋의 되돌리기를 사용할 수 있습니다. 적용 대상은 열린 초안입니다. 프리셋 저장·History 기록·이미지 생성·유료 호출은 전송으로 실행되지 않습니다.

리더는 확인한 실행 파일과 수신 규약 `chaessi.prompt-transfer/1`을 검증합니다. 공식 v3.8.5는 2026-11-23 수정본을 사용하세요. Portable이 풀어 놓은 임시 EXE 대신 다운로드한 Portable 파일을 지정하세요. 경로를 옮겼으면 파일을 다시 선택하세요. 같은 경로의 공식 서명 패키지 업데이트는 새 서명과 실행 프로세스를 재검증해 연결하며 매번 다시 등록할 필요는 없습니다. 초안이나 슬롯이 바뀌면 리더가 받을 칸을 확인하고, 다시 선택할 항목을 표시합니다.

캐릭터는 번호를 건너뛰거나 역순으로 지정할 수 있습니다. 예를 들어 기존 캐릭터가 1명일 때 **캐릭터 4 (새로 만들기)**로 보내면 2·3번은 빈 꺼짐 슬롯이 됩니다. 생성 범위는 프리셋 미리보기에서 확인하고 적용하며, 취소하면 만들지 않고 되돌리면 함께 제거합니다. 기존의 다른 슬롯 내용은 유지됩니다. 목록의 **위로 / 아래로**는 같은 칸으로 보낼 문구의 적용 순서를 바꿉니다.

## 문제 해결, 업데이트와 제거

- **설치 파일이 차단됨** — 이 설치 파일에는 코드 서명이 없어 Windows가 알 수 없는 게시자로 표시할 수 있습니다. 릴리스의 파일명과 SHA-256을 대조하고, 해시가 다르면 실행을 중단하세요. 조직 정책이 설치·Chrome 개발자 모드를 차단하면 관리자에게 확인하세요.
- **연결 대기 중** — 같은 Chrome 프로필에서 확장이 켜졌는지, 리더가 한 개만 실행 중인지 확인하세요. 확장 설정의 키가 잘못됐다면 **연결 해제** 후 리더에서 다시 복사해 저장하세요. Inspect 권한과 열린 이미지도 확인하세요.
- **프리셋 연결 실패** — 공식 Portable의 위치와 빌드를 확인하세요. 파일을 이동했다면 다시 선택하세요. 같은 경로의 정상 서명 업데이트는 재검증 후 다시 연결합니다. 같은 실행 파일로 프리셋을 다시 열면 리더가 연결을 다시 시도합니다. 목록에 다시 선택하라는 표시가 있는 행의 받을 칸을 확인하세요.
- **업데이트·복구** — 리더를 정상 종료하고 이 1.1.1 Setup을 실행하세요. 승인된 공식 1.0.x 및 1.1.0의 정확한 전체 파일 기준을 검사하고 검증된 기존 C·D 또는 사용자 선택 위치를 유지합니다. 폴더 선택만으로 기존 설치를 승인하지 않으며, 변조·혼합·알 수 없는 빌드는 허용하지 않습니다. 중단된 작업은 같은 Setup을 다시 실행해 복구 안내를 따르세요. 충돌이 나면 기존 파일과 기록을 보존하세요. 예전 보호 없는 Setup을 나중에 실행하는 것까지 이 설치기가 막을 수는 없으므로 구 설치기로 덮어쓰지 마세요. 연결된 Chrome 확장 0.3.1과 설정은 유지하세요.
- **이전 개발용 리더에서 옮기기** — 이전 리더를 닫으세요. 새 리더의 **Chrome 연결 설정 → 이전 리더 폴더 선택**에서 이전 리더가 들어 있는 폴더를 지정하면 기존 키를 가져올 수 있습니다. Chrome 프로필과 확장 폴더를 유지하면 기존 확장 ID와 권한도 유지됩니다. 이전 폴더를 안전하게 읽을 수 없으면 리더의 현재 연결키를 복사해 확장에 저장하세요. 현재 사용자용 복구 폴더의 접근이 거부되면 키는 그대로 유지되므로 해당 폴더의 권한을 확인한 뒤 다시 시도하세요.
- **제거** — Windows 설정의 **앱 → 설치된 앱**에서 리더를 제거하세요. 확장은 `chrome://extensions`에서 따로 제거한 뒤 전용 압축 해제 폴더를 지울 수 있습니다. 리더를 제거해도 사용자 설정과 프리셋 자료는 보존됩니다.

## 이 PC에 남는 정보

수집 원문·편집본·보낼 문구는 리더 실행 중에만 유지됩니다. 새 자료로 교체하거나 종료하기 전에 필요한 문구를 복사하세요. 언어, 프리셋 실행 파일 지정, 연결키는 Windows 사용자별로 저장됩니다. Chrome도 해당 프로필에 연결키와 허용한 권한을 보관합니다. 키는 이 PC의 확장 설정에만 붙여넣으세요. 리더와 확장은 루프백으로 통신하며 수집은 가져오기 버튼을 눌렀을 때 시작됩니다.

## 서명된 프리셋 패키지

공식 **Preset 3.9.1**은 [별도 릴리스](https://github.com/DooMokDdongGae/Chaessi-Preset/releases/tag/v3.9.1)의 Windows x64 ZIP으로 안내합니다. Reader와 공개 준비가 병행되므로 링크와 파일이 실제 제공되는지 확인하세요. ZIP의 EXE와 서명·명세 파일 4개를 함께 보관하세요. 기존 **공식 3.8.5의 2026-11-23 수정본**도 계속 지원합니다. 임의의 무서명 PRIVATE 빌드는 지원하지 않습니다. 서명 패키지는 `chaessi.prompt-transfer/1`과 PUBLIC 생산 신뢰를 모두 만족해야 하며, 이 조건만으로 모든 미래 버전의 호환을 보장하지 않습니다.

서명 Portable은 EXE 옆에 다음 파일 4개가 함께 있어야 합니다. `<EXE 파일명>`에는 `.exe`를 포함합니다.

- `<EXE 파일명>.chaessi-release.json`
- `<EXE 파일명>.chaessi-release.sig`
- `chaessi-publisher-keys.json`
- `chaessi-publisher-keys.sig`

전체 공식 패키지를 함께 보관·갱신하고 서명 파일을 편집하지 마세요. unpacked 배포는 전체 폴더 구조도 유지해야 합니다. 리더는 발행자 키와 서명·유효 기간·폐기·최고 순번, 전체 리소스, 실제 수신 프로세스 및 소켓을 확인한 뒤 기존 요청별 nonce/HMAC 인증을 사용합니다. 시험 키는 신뢰 대상이 아닙니다. 생산 신뢰 채널은 `public`, 저장 영역은 `public-production`입니다. 오류가 나면 PC 날짜·시간을 확인하고 완전한 최신 공식 패키지를 다시 선택하세요. 검증을 끄거나 예외로 실행하는 기능은 없습니다.

## PNG 입력과 편집

프롬프트 메타데이터가 들어 있는 PNG를 리더 창에 드롭하거나, 지원되는 PNG 파일·이미지 클립보드를 붙여넣어 오프라인으로 가져올 수 있습니다. 일반 텍스트를 편집칸에 붙여넣는 동작은 텍스트 편집용입니다. 이미지에 메타데이터가 없으면 프롬프트를 추정해 만들지 않습니다. 긴 문구는 편집칸을 확대해 읽고 접어 원래 배치로 돌아갈 수 있습니다. 자료 교체 확인이 나오면 기존 편집과 보낼 문구를 확인한 뒤 진행하세요.

## 검증 범위와 알려진 제한

- 기존 격리 서명 후보에서 미리보기 전송 약 **6.97초**, 전체 인증 약 **14.35초**가 관찰됐습니다. 환경과 패키지 크기에 따라 수초 이상 기다릴 수 있으며 보장 응답 시간이 아닙니다. 같은 전송을 반복해서 누르지 말고 결과를 확인하세요.
- 꺼진 Preset을 처음 실행한 직후에는 발견에 실패할 수 있습니다. 프리셋 화면이 준비된 뒤 **프리셋 연결**을 다시 시도하세요. 초안 revision이나 슬롯 변경은 프로세스 연결 종료와 별개이며 받을 칸을 다시 확인할 수 있습니다.
- 검증된 개발 기준의 격리 Windows 실기 중 D 없는 신규 설치, 기본·한글·공백·다른 볼륨 경로, 기존 C/D 제자리 업데이트, 실제 교체 실패·롤백·같은 Setup 재시도, 제거·설정 보존, Chrome 0.3.1 재페어링 없는 재연결과 합성 PNG 입력·편집 근거를 재사용합니다. 이를 새 PUBLIC 빌드를 모든 PC에서 다시 시험한 결과로 확대하지 않습니다. 최종 공개 조합의 최소 연결 검증은 배포 검수 기록과 구분합니다.
- 온라인 Chrome/NovelAI Inspect 수집 전체를 이번 공개 전환에서 다시 시험하지 않았습니다. 브라우저의 **이미지 복사**는 메타데이터를 제거할 수 있으므로 원본 PNG 파일을 사용하세요. 실제 제공자의 원형 Precise/Character PNG 표본과 일부 외부 이미지 처리 경로는 미검증입니다. 저장 중 busy 타이밍의 실제 관찰도 완료하지 않았습니다.
- 오프라인 상태에서는 아직 받지 않은 발행자 키 폐기 정보를 알 수 없습니다. 시스템 시계와 같은 사용자 저장소 훼손도 보호의 운영 한계입니다.
