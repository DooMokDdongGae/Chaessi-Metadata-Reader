브라우저에서 원본 JSON 저장

아래 링크를 브라우저의 북마크바로 끌어 놓으세요. 북마크바는 Chrome과 Edge에서 Ctrl + Shift + B로 표시할 수 있습니다.

채씨 · 보이는 JSON 저장

작품 화면에서 사용하기

  1. 브라우저에서 볼 수 있는 aitag.win 작품을 열고 원하는 이미지의 원본 JSON을 선택하세요.
  2. 접힌 내용은 펼치고, 저장할 원본 패널 하나가 화면에 보일 때 북마크를 누르세요.
  3. 채씨 메타데이터 리더의 파일 열기…에서 다운로드한 JSON 파일을 여세요.

사이트의 강조 표시나 미리보기 때문에 원문을 확인할 수 없으면 저장이 중단됩니다. 이때는 사이트에서 원본 JSON을 복사해 리더의 ‘JSON 입력…’에 붙여넣으세요.
