# Chaessi Metadata Reader 1.0.1

Windows x64 · 2026-11-25 · Build `reader-20261125-01` (`2026112501`)

- **Connect to Preset.** In the send window, select the official corrected CHAESSI PRESET v3.8.5 Portable EXE once. Reader authenticates the selected app and starts it on connection if it is closed.
- **Send after editing.** Reader rechecks destination fields when the Preset draft changes. In Preset, preview the current and final text, then apply or cancel. You can undo immediately after applying.
- **One Setup.** Use `Chaessi-Metadata-Reader-Setup-x64.exe` for a fresh install or to update an official 1.0.0 installation. Finish your work and close Reader first. Keep your settings and any paired Chrome extension 0.3.1. Unpack and load the separate extension ZIP for a first installation.

Rerunning the Setup checks the installed build. If a file update was interrupted, rerun the same Setup to recover. [Install and use Reader](README.en.md) · [Setup prompt for Codex, Claude Code, or ChatGPT](README.en.md#ai-setup) · [Previous 1.0.0 build](https://github.com/DooMokDdongGae/Chaessi-Metadata-Reader/releases/tag/v1.0.0%2B2026112401)

For a first installation, extract the extension ZIP to a permanent folder and load it as an unpacked Chrome extension. Paste the pairing key only into the extension settings and approve NovelAI Inspect access yourself. Keep any working 0.3.1 installation.

Older Setup files without version protection can overwrite a newer installation. Keep those installers away from an installed 1.0.1. If installation is interrupted, close Reader normally and rerun the same official v1.0.1 Setup. If it reports an unsupported or modified installation, preserve the current files and settings and record the error message.

An isolated Windows environment verified fresh installation, an in-place update from the official 1.0.0, removal, Preset transfer, and automatic Chrome reconnection. Import from the live NovelAI Inspect site was outside the scope of the offline test.
