# Chaessi Metadata Reader 1.1.0

Windows x64 · 2026-11-26 · Build `reader-20261126-01-public` · Sequence `2026112601`

[Official 1.1.0 release](https://github.com/DooMokDdongGae/Chaessi-Metadata-Reader/releases/tag/v1.1.0) · [Latest stable release](https://github.com/DooMokDdongGae/Chaessi-Metadata-Reader/releases/latest) · [Install and use](README.en.md) · [AI setup-assistant prompt](README.en.md#ai-setup)

- **Official signed-package verification.** PUBLIC production trust checks publisher keys, signatures, validity, revocation, highest accepted sequences, all resources, the actual receiving process and socket. Test keys and arbitrary unsigned PRIVATE builds are not accepted. Keep a signed Portable's EXE and its four signature/key files together. This does not announce an already published new Preset release.
- **Official 3.8.5 stays supported.** The corrected 2026-11-23 official CHAESSI PRESET 3.8.5 Portable, `chaessi.prompt-transfer/1` and per-request nonce/HMAC authentication remain supported. Choose Base/Character Positive/Undesired, then preview, cancel, apply or Undo in Preset. Sending does not save, create History or generate images.
- **One Setup.** `Chaessi-Metadata-Reader-Setup-x64.exe` handles a fresh install to `D:\MApp\Chaessi Reader` and upgrades from exact approved official 1.0.x/D relocation `2026112502` baselines. Arbitrary folders, mixed or modified files and unknown builds are refused. Close Reader normally first. Settings, pairing, registrations and Chrome extension **0.3.1** are retained. Only for a first extension install, extract the ZIP to a permanent folder and let the user load it and review initial permission in Chrome.
- **Recovery and old installers.** After an interruption, rerun the same Setup and follow recovery instructions. Preserve files and records if a conflict is reported. Old unprotected installers cannot be prevented from running later; do not overwrite with an old Setup. The Windows installer has no code signature: verify filenames and SHA-256, and respect security policies.

## Known limitations and verification scope

Earlier isolated signed-candidate measurements observed approximately **6.97 seconds** for preview transfer and **14.35 seconds** for full authentication. These are not guaranteed times for this public build; waits depend on environment. If discovery fails just after Preset starts, wait for its window and retry the connection. Existing installation, D upgrade, rollback, removal, UI, transfer and offline-PNG evidence was reused. Full online Chrome/NovelAI Inspect collection was not rerun on the latest candidate. Unreceived offline revocations, the local clock and damage to same-user storage remain operational limitations.
