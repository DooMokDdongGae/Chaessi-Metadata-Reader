## Windows アプリと Chrome 拡張機能をインストールする

Windows 10 または 11 の x64 版と、Chrome 120 以降を用意してください。Python と Tk はアプリに同梱されています。開発ツールのインストールは不要です。

1. このリリースから **Chaessi-Metadata-Reader-Setup-x64.exe** と **Chaessi-Metadata-Reader-Chrome-Extension.zip** をダウンロードします。PowerShell で `Get-FileHash -Algorithm SHA256 "ファイル名"` を実行すると、リリースに記載された SHA-256 と照合できます。
2. リーダーが起動中の場合は作業を終えて閉じます。同じ **Setup** で現在の Windows ユーザー用に新規インストールするか、公式版を更新できます。スタートメニューから **Chaessi Metadata Reader** を開きます。新規インストール時はデスクトップのショートカットも選べます。
3. 拡張機能 0.3.1 が接続済みの場合はそのまま使えます。初めてインストールする場合は ZIP を今後も使うフォルダーに展開します。Inspect を使う Chrome プロファイルで `chrome://extensions` を開き、**デベロッパー モード**を有効にします。**パッケージ化されていない拡張機能を読み込む**を押し、**manifest.json が入っているフォルダー**を選びます。
4. **채씨 메타데이터 리더 연결** のカードでバージョン **0.3.1** を確認します。Chrome はこのフォルダーを参照するので、拡張機能を使っている間は同じ場所に置いてください。[Chrome の読み込み手順](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

## 初回の接続設定

拡張機能の設定画面は韓国語です。以下に実際のボタン名を示します。

1. リーダーで **Chrome 接続設定 → 接続キーをコピー** を選びます。Chrome の拡張機能メニューからリーダーの拡張機能を開きます。
2. **리더의 연결 키**（リーダーの接続キー）に貼り付け、**최초 연결 저장**（初回接続を保存）を押します。続いて **NovelAI Inspect 접근 허용**（Inspect へのアクセスを許可）を押し、Chrome の確認画面で `novelai.net` の権限を許可します。
3. リーダーで Chrome の接続を確認したら、設定タブを閉じてかまいません。次回からは同じプロファイルの Chrome とリーダーを開くと自動で再接続します。Chrome の休止状態によっては 30 秒以上かかります。

## 画像からプリセットの下書きに送る

1. NovelAI Inspect で画像を開き、**Simplified** の内容を確認します。リーダーで **NovelAI Inspect から取り込む** を押します。Inspect のタブが複数ある場合は、先に目的のタブを選んでください。
2. **取り込んだ画像**から画像を選び、ベースまたはキャラクターの**ポジティブ**・**除外プロンプト**を編集します。**テキストをコピー**で現在の編集内容をコピーできます。**取り込み元の原文を表示**で原文を確認し、**原文に戻す**でその欄だけ元に戻せます。
3. 一部をドラッグして**選択部分を追加**するか、欄全体を送る場合は**全文を追加**します。追加した文章はその時点のコピーです。後から編集した文章を送るには、もう一度追加してください。
4. リーダーの **プリセットに送る → 実行ファイルを選択・変更** で、公式 Portable の `Chaessi-Preset-v3.8.5-x64.exe` を一度選んで確認します。**プリセットに接続** を押すと、指定した実行ファイルに対応するプリセットに接続し、起動していなければ起動します。[CHAESSI PRESET v3.8.5](https://github.com/DooMokDdongGae/Chaessi-Preset/releases/tag/v3.8.5)
5. 送りたい行を選び、**送信先のプロンプト欄**を指定します。**末尾に追加**は両方の文章が空でなければコンマと半角スペースで連結し、**上書き**はその欄の内容を置き換えます。すべての行に送信先を指定して **プリセットに送る** を押すと、一覧の全項目を上から順に送ります。1件だけ送るには、他の項目を一覧から外します。原文と編集欄はそのまま残ります。
6. **プリセット側**で変更前と変更後の文章を確認して、適用またはキャンセルします。適用直後はプリセット側で元に戻せます。適用先は開いている下書きです。転送によるプリセット保存、History への記録、画像生成、有料 API 呼び出しはありません。

リーダーは実行ファイルを確認し、`chaessi.prompt-transfer/1` で受信側を認証します。公式 v3.8.5 は 2026-11-23 修正版をお使いください。一時展開された EXE ではなく、ダウンロードした Portable 本体を選びます。場所を移動した場合はもう一度選んでください。同じ場所の公式署名付き更新は新しい署名とプロセスを再検証するため、公開ごとに再登録する必要はありません。下書きや枠を変更すると、リーダーが送信先を再確認し、選び直す必要がある行を示します。

キャラクター番号は飛ばしたり、逆順で指定したりできます。既存のキャラクターが1人のとき **キャラクター 4（新規作成）** に送ると、2・3番は空のオフ枠になります。作成範囲をプリセットのプレビューで確認してから適用します。キャンセルでは作成されず、元に戻すと追加した枠も一緒に削除されます。無関係な既存の枠は保持されます。一覧の **上へ / 下へ** は同じ欄へ送る文章の反映順を変えます。

## 困ったとき・更新・削除

- **インストールがブロックされた場合**　インストーラーはコード署名されていないため、Windows が発行元を不明と表示することがあります。リリースのファイル名と SHA-256 を照合し、異なる場合は実行を中止します。組織の方針でインストールや Chrome のデベロッパー モードが制限されている場合は、管理者に確認してください。
- **Chrome の接続待ちが続く場合**　同じプロファイルで拡張機能が有効か、リーダーが一つだけ起動しているか確認します。キーを訂正するには拡張設定で **연결 해제**（接続解除）を押し、もう一度コピーして保存します。Inspect を取り込めない場合はサイトの権限と表示中の画像も確認してください。
- **プリセットに接続できない場合**　公式 Portable のビルドと保存場所を確認します。場所を移動した場合はファイルを選び直します。同じ場所の正規署名付き更新は再検証して接続します。同じプリセットを開き直すと、リーダーが再接続を試みます。送信先の選択が必要と表示された行は、欄を確認してください。
- **更新・復旧**　リーダーを通常の手順で終了し、この 1.1.0 Setup を実行します。登録された公式 1.0.x と D 移行版 `2026112502` の正確な全ファイル基準を確認します。任意のフォルダー、改変・混在したファイル、不明なビルドは拒否します。中断後は同じ Setup を再実行して復旧の案内に従ってください。競合が表示されたら、ファイルと記録を保持してください。このインストーラーは、保護のない古い Setup を後で実行することまで防げません。古いインストーラーで上書きしないでください。接続済みの Chrome 拡張機能 0.3.1 と設定は保持します。
- **以前の開発版から移行**　以前のリーダーを閉じます。インストール版の **Chrome 接続設定 → 以前のリーダーフォルダーを選択** で以前のリーダーのフォルダーを指定すると、接続キーを引き継げます。Chrome のプロファイルと展開先を維持すれば、既存の拡張機能 ID と権限も引き継げます。以前のフォルダーを安全に読み取れない場合は、リーダーの現在の接続キーをコピーして拡張設定に保存してください。現在の Windows ユーザーの復旧フォルダーへのアクセスが拒否された場合、キーはそのままです。フォルダーのアクセス権を確認してから再試行してください。
- **削除**　Windows の **設定 → アプリ → インストールされているアプリ** からリーダーをアンインストールします。拡張機能は `chrome://extensions` から個別に削除します。その後に専用の展開フォルダーを削除できます。リーダーのアンインストール後もユーザー設定とプリセットのデータは残ります。

## この PC に保存される情報

取り込んだ原文、編集内容、送信待ちの文章は起動中のセッションで保持されます。別の資料に入れ替えたり終了したりする前に、残したい文章をコピーしてください。言語、選んだプリセットの実行ファイル、接続キーは Windows ユーザー別に保存されます。Chrome にもプロファイルごとにキーとサイトアクセス権が保存されます。キーの貼り付け先はこの PC の拡張設定だけです。リーダーと拡張機能はループバックで通信し、読み取りは取り込みを操作したときに始まります。

オフラインの**ヘルプ**には、aitag.win のウェブ投稿を取り込む方法と転送結果の確認方法もあります。[サードパーティーソフトウェアに関する表記](THIRD-PARTY-NOTICES.md)

## 署名付きプリセットパッケージ

**公式 Preset 3.8.5 の 2026-11-23 修正版**は引き続き対応します。任意の署名なし PRIVATE ビルドは対応しません。今後公式署名付きパッケージを使う場合は、`chaessi.prompt-transfer/1` と PUBLIC 本番信頼の両方を満たすものを選んでください。この案内は新しい Preset 公開版の発行を意味しません。

署名付き Portable では EXE の隣に以下の4ファイルが必要です。`<EXE ファイル名>` には `.exe` を含みます。

- `<EXE ファイル名>.chaessi-release.json`
- `<EXE ファイル名>.chaessi-release.sig`
- `chaessi-publisher-keys.json`
- `chaessi-publisher-keys.sig`

公式パッケージ全体を一緒に保管・更新し、署名ファイルは編集しないでください。unpacked 配布ではフォルダー構成全体も保持してください。リーダーは発行者キー、署名、有効期間、失効、受理済み最高シーケンス、全リソース、実際の受信プロセスとソケットを確認してから、従来のリクエストごとの nonce/HMAC 認証を使います。この PUBLIC 版は試験キーを信頼しません。エラー時は PC の日時を確認し、完全な最新公式パッケージを選び直してください。検証を無効にしたり信頼の例外を作ったりする機能はありません。

## PNG の取り込みと編集

プロンプトのメタデータを含む PNG をリーダーへドロップするか、対応する PNG ファイル・画像クリップボードを貼り付けてオフラインで取り込めます。編集欄への通常テキストの貼り付けは文章編集用です。メタデータがなければプロンプトを推測して作ることはありません。長文は編集欄を拡大して読み、折りたたんで元の配置に戻せます。取り込み内容を置き換える確認が出たら、編集内容と送信待ちの文章を確認してから進めてください。

## 検証範囲と既知の制限

- 以前の隔離署名候補では、プレビュー転送が約 **6.97秒**、全体認証が約 **14.35秒**でした。環境とパッケージサイズにより数秒以上待つことがあります。今回の公開版の応答時間を保証する数値ではありません。送信を繰り返さず、結果を待ってください。
- 終了中のプリセットを起動した直後は検出に失敗することがあります。画面の準備ができてから **プリセットに接続** を再試行してください。下書き revision や枠の変更はプロセス接続の寿命とは別で、送信先の再確認が必要になることがあります。
- 従来のインストール、D 更新、ロールバック、削除、UI、転送、オフライン PNG の検証記録を再利用しました。最新候補でオンラインの Chrome/NovelAI Inspect 取り込み全体は再試験しておらず、すべての PC 環境を検証したものではありません。
- オフラインでは、まだ受け取っていない発行者キーの失効情報を確認できません。システム時計と同じユーザーが書き込める保存領域の破損も運用上の制限です。
